
# 🌦️ SkyCast — Live Weather

A modern, responsive weather application built with React and Vite.

## 🌐 Live Demo
🚀 [Visit SkyCast](https://skycast-liveweather.vercel.app/)

## ✨ Features
- 🌍 Worldwide city search
- 🌤️ Current weather and forecasts
- 🌧️ Weather condition intensity
- 🕒 Pakistan live clock
- 🌙 Dark mode
- 📱 Responsive design
- ⚡ Animated neon loading screen

## 🛠️ Tech Stack
- React + Vite
- JavaScript
- CSS
- Open-Meteo API
- Vercel

## 🚀 Run Locally
```bash
npm install
npm run dev
```
